# Selected coursework · Ahmed Balatif

Four small projects from my computer science courses at Prince Sultan University. Each folder has a runnable example and credits for the people who worked on it.

| Project | What to try |
| --- | --- |
| [Caesar cipher decoder](caesar-cipher-decoder/) · Java | Decode a message using a common-word heuristic, then see what happens with a two-letter input. |
| [Student attendance](student-attendance/) · Java | Import one fictional student, view attendance, and export a summary. I wrote the teacher class and integrated the team’s classes. |
| [Linear system solver](linear-system-solver/) · Python + NumPy | Solve a three-equation system with two unknowns. |
| [Parallel array benchmark](parallel-array-benchmark/) · Java | Compare a serial calculation with the same calculation split across worker threads. |

Use JDK 11 or newer for the Java examples. The first three folders contain portfolio copies with the adaptations documented in their READMEs.

My larger course projects have their own repositories: [solar forecasting](https://github.com/balatifahmed-ai/CS316_Project) and [Java word index](https://github.com/balatifahmed-ai/CS210Project).
